# Public design direction
Cream #fbf8f2, pale lavender #eee8f6, purple #6441a5, ink #271d31, white #ffffff. Cormorant Garamond carries the club's expressive editorial voice; DM Sans carries navigation and practical details. Headline is centered, event information is left aligned. Real photographs and the original flower anchor the identity. The one broad visual gesture is a panoramic DC skyline followed by a generously scaled community montage.

Header / centered live tagline and join action / skyline / upcoming events / real community photos / invitation / footer.

Reviewed against brief: no decorative metrics, fake events or generic feature cards. Original banner contains its own tagline; its skyline is intentionally cropped to keep the live accessible headline the focal point. Italic tagline accent follows the user's standard over the frontend skill's default preference.
